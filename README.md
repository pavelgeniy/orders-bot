# Бот мониторинга заказов

Каждые 10 минут проверяет биржи и Telegram-каналы, фильтрует по ключевым словам и присылает новые заказы в Telegram-группу. Работает бесплатно на GitHub Actions, без ИИ.

## Файлы
- `bot.py` — сам бот (Python, без внешних библиотек).
- `config.json` — ключевые слова, минус-слова и список источников. Правится прямо на GitHub (значок карандаша).
- `seen.json` — список уже обработанных заказов (создаётся сам).
- `.github/workflows/monitor.yml` — расписание запуска.

## Секреты (Settings → Secrets and variables → Actions)
- `BOT_TOKEN` — токен от @BotFather
- `CHAT_ID` — ID группы

## Как добавить источник
- Telegram-канал: допишите его username в `sources.telegram` (только публичные каналы).
- Ключевое слово: допишите в `keywords`. Слово ищется по началу: `продвиж` найдёт «продвижение» и «продвижения».

## Проверка на своём компьютере
```
DRY_RUN=1 python3 bot.py
```

## Автоотклики на Freelancehunt (`autobid.py`)
Дважды в день (окна 7:00–12:00 и 19:00–24:00 по Киеву, по одному разу в каждом) берёт новые проекты Freelancehunt за последние 14 часов, отбирает по темам из `autobid.json`, подставляет шаблон отклика на языке проекта (укр / рус / англ) и отправляет ставку через API. Итог (что отправлено, ошибки) приходит в ту же Telegram-группу.

- Секрет `FH_TOKEN` — API-ключ со страницы https://freelancehunt.com/my/api2. Без него бот присылает в Telegram готовые тексты откликов, чтобы вставить вручную.
- `autobid.json`: `mode` (`auto` — отправлять, `draft` — только тексты), лимит ставок за запуск, цена (95% бюджета проекта, минимум 700 грн; без бюджета — цена темы), сроки, шаблоны по темам, минус-слова.
- `autobid_state.json` — какие проекты уже получили ставку (создаётся сам).
- Ручной запуск: Actions → autobid-freelancehunt → Run workflow → галочка «Отправить отклики прямо сейчас».
- Лимит Freelancehunt — около 20 ставок в сутки, поэтому по умолчанию не больше 10 за запуск.
